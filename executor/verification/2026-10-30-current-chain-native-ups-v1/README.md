# Current-chain Native and ordinary UPS resource evidence

Read the [review report](../../../docs/security/CURRENT_CHAIN_USER_UPS_PREFLIGHT_20261030.md)
before interpreting this bundle. It is preflight evidence, not deployment,
complete transaction proof, finality, random ordering or ordinary-wallet arrival.

`manifest.json` lists every exact member and its SHA256/size, and the SHA256 of
`evidence.tar.gz`. Paths are relative to the unpacked bundle.

- `capture-v3/`: final bounded Node captures, checkpoint context, exact public
  circuit registry, registration lookup/proof and public faucet configuration.
- `capture/`, `capture-v2/`: original TLS failures and successful Node control.
- `native-bound-sealed-v4/`: definitive final-binary Native artifact/binding.
  `native-bound-v2/` retains the earlier pre-seal check separately.
- `public/ORDINARY-RESOURCES-SEALED-v4.json`: eleven source-built verifier
  identities and whitelist/aggregation checks. Common data is compiled from the
  frozen source; runtime common bytes and CST are not supplied by that API.
- `public/REGISTRATION-v1.json`: current URT/checkpoint replay for public user
  223232 despite its uninitialized stored user leaf.
- `funding-reconciliation-v1/`: all 200 original read requests/responses and
  summary across the exact 100 advertised historical/current faucet operators.
  Zero pending there does not resolve the original unknown faucet request.
- `public/`: bounded plans, failed/successful builds, Rust/Node tests, independent
  review limits, browser results, zero-fee accounting and closing source checks.
- `application-v2/`, `application-v4/`: source-snapshot digest manifests.
- `inputs/`: canonical Native layout ABI; `capture-tools/`: immutable acquisition
  and packaging scripts, including failures. They are historical scripts with
  local paths, not permission to replay financial work or user browser spaces.

No binary executable, wallet/private-key file, mnemonic, hydrated signing trace or raw
private faucet proving diagnostic is included. `private_note_*` registry entries
are public circuit verifier metadata; privacy/ECDSA roles were not compared or
authorized by the ordinary-ZK resource result.

New financial requests, business proofs, deployments, real fills and ordinary
claims are all zero. The original faucet send lock remains intact; no retry,
replacement recipient, alternative proof key or old-contract update occurred.
