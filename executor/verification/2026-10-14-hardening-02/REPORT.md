# 三市场执行器校验与恢复优化 — 2026-10-14

## 实现

- **Token ABI**：启动前检查两 limb 余额位置、sent/claimed 位置、四槽位 outbox 结构、方法 ID 唯一性和 claim/transfer 的参数类型、长度。错误 ABI 在读取链状态或启动证明前被拒绝。
- **提交与恢复**：复核完整 UPS 的市场、指纹、费用、金库，以及验证输出与广播标记中的叶哈希一致性；日志路径限定到当前任务的确切 UUID 文件。
- **中断后的明确拒绝**：如果独立证明进程留下明确的“广播前拒绝”终止记录，重启后会保存真实失败原因并释放旧意图。缺失、不完整日志以及未确认广播继续阻止重发。
- **公共状态读取**：逐个校验 realm 高度；在发出状态读取前拒绝无效用户 ID、合约 ID、槽位和公钥哈希。重复 ABI 字段也会被拒绝。
