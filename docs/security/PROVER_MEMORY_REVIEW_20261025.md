## 具体修改与验收范围

- 普通钱包在独立、独占创建的 lifecycle JSONL 中同步保存启动、进程、ready、派发、原生返回、身份核验及结束时刻。成功 ACK 后外层指标发生错误，也保留已观察时刻；失败不触发重签或付款重试。
- 新的严格资源观察器按发布清单的真实二进制 SHA256 选择进程，覆盖普通钱包、完整市场证明器及其 sealed 副本；记录 PID、父 PID、观察器和发布清单身份。1 秒 RSS 采样不能代表精确峰值或整机物理内存。
- 应用侧可选 `proverMemoryMode: release-unused-v1`：完整签名/证明生成后释放交易会话；macOS 分配器只回收已不用的内存页。公共电路保持常驻，完整证明、实际调用栈、会话签名、费用、网络和最终状态端点校验保留。
- 默认仍为 `retain-v1`；其他平台不能把不支持的回收模式静默当作成功。候选必须根据真实成交的测量结果决定是否保留。
