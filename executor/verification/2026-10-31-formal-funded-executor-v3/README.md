# Formal funded Executor: public synthetic evidence

Read [the implementation, failure, measurements and remaining gates](../../../docs/security/FORMAL_FUNDED_EXECUTOR_20261031.md).

This publication has one coherent **synthetic** 12-UPS lifecycle: six ordinary
signatures and six v14 SDK signatures from an empty registered vault through
initialization, order funding, fee exhaustion/recovery, settlement and ordinary
FT/change claims. It also preserves eight accepted UPSs and the rejected
maintenance-tape prefix from an earlier, separate synthetic identity cohort.
The two cohorts must not be joined. No network registration, trade, claim,
wallet approval or financial operation is added.

The formal factory, native driver and durable lifecycle are real application
code. Transport tests use explicit driver doubles; the actual final native driver rejects direct submit before reading its policy;
its build/identity matches the complete-UPS spending key. Its live registration/
preflight/broadcast path has not completed network acceptance. Candidate
`allow_broadcast` remains false. Book/NFT cannot use the v14 AMM/Curve route.

The [manifest](manifest.json) records exact uncompressed and gzip SHA256 values
for every public member. Request/Endcap/key-proof bytes, explicit public session
projections, source/current openings, generated bytecode, source snapshots,
failed runs, dependency pins, timings, RSS samples and regression logs are
included. Wallets, binaries, private keys, mnemonics, raw signing/CFC witnesses
and dependency source trees are excluded.

Important records (paths refer to `source` in the manifest):

- `public/PLAN.json`, `public/PLAN-v2.json`: original bounds and explicit bounded
  correction, preserving all finance ceilings.
- `public/CLOSED-v1.json` / `public/lifecycle-v1.log`: original failure and all
  memory samples; `lifecycle-v1/` has eight completed requests.
- `public/CLOSED-v2.json`, `lifecycle-v2/REPORT.json`, `public/METRICS-v2.json`:
  final correctness lifecycle and timing scope.
- `public/INDEPENDENT-v10.json`: 20 separately verified fixed-resource Endcaps,
  metadata and changed-public-fee rejection. It does not independently establish
  approved calls or finality.
- `public/CONSISTENCY-v4.json`: actual public graph/fee audit. Earlier v2/v3
  outputs are empty failed auditor attempts (URL encoding, then fractional
  timing JSON); they are retained and are not successful audit reports.
- `public/regression-final-v11.log`: 87 scoped host passes;
  `public/transport-unit-v10.log`: four transport passes;
  `public/early-validation-v13.log`: two pure stale-tape/source and direct-action rejections;
  `public/audit-regression-v11.log`: graph/fee/source substitution checks.
- `public/FINAL_NATIVE-v12.json`, `public/native-identity-v12.log` and
  `runtime-fixture-v1/`: build identity and synthetic instance binding;
  financial broadcasting is disabled.
- `public/READ_PLAN-v1.json`, `public/CURRENT_READ*.json`: eight bounded reads.
  Realm 0 root/head 29242 and one QA-8 zero slot respond; other endpoint TLS
  failures prevent a complete live preflight. A zero slot is not deployment,
  asset balance, full metadata repair or consensus-finality evidence.

## Reproduce without sending

Verify/decompress each manifest member into a **fresh** directory using its
`source` path. Never extract over original source, wallet/runtime or evidence.
Freeze/materialize SDK commit `c92880c8b6e2c8d392f19368bc8801a2584fd427` with
the existing `batching/dependencies` workflow, then create a fresh test-only
application snapshot using `prepare_mainnet_beta_application.py --source ...
--out ... --test-only`. This keeps the SDK unpatched.

Use `nightly-2025-09-20`, Cargo `--offline --locked --release`,
`PSY_NETWORK=testnet`, `PSY_MARKET_TESTNET_PROFILE=mainnet-beta-20261027-v1` and
`RAYON_NUM_THREADS=2`. Set `BATCH_BUILD` to the extracted `fixtures` directory,
`BATCH_MINIMAL_GENESIS=1` and `FUNDED_LIFECYCLE_OUT` to an absent output path.
Run test target `batch_lifecycle`, filter
`fresh_curve_lifecycle_with_ordinary_claim_and_exhausted_fee_recovery`, with
`--ignored --nocapture --test-threads=1`. Predeclare the same 12-UPS/1,900-second,
10-GiB sampled-family-RSS maximum and retain failures. Test keys are fixed public
synthetic keys and must never be registered/funded on a live network.

`verify_saved_ups` re-verifies each public request against the frozen verifier
and common data without RPC. Run
`node batching/checkpoint-stream/audit-funded-lifecycle.mjs EXTRACTED/lifecycle-v2`
for the separate consistency audit. Host regressions live in
`executor/funded*.test.mjs`; these are not payment proof/receipt acceptance.

Synthetic process timings and sampled RSS are not matched network performance,
physical footprint, p95, TPS, cross-machine coordination or production signoff.
