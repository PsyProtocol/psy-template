# Initial offline Markets UI evidence — superseded visual baseline

This immutable archive preserves the initial build/dependency/browser observations,
including the rejected generic Psi branding, Chinese interface and purple theme.
It is **not the current visual acceptance**. See [v2](../2026-10-26-market-ui-v2/README.md)
for official Psy assets, English copy and current shared editorial styling.

The initial dialog backward-focus escape was fixed and retested; its failure is
retained. The initial vulnerable UI toolchain audit and failed install attempts
are retained alongside the subsequent frozen install, successful build and zero
known vulnerability audit. The production app has no live signing or submission
path. These observations are frontend-only, not chain/security/performance acceptance.

`manifest.json` binds 45 exact originals; `ARCHIVE-INTEGRITY-v1.json` records
comparison to the original local run. Screenshot originals are separately bound
by `SCREENSHOTS-v1.json`. No original file or screenshot has been overwritten.
The v2 privacy scan also includes this archive.
